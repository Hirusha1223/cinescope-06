පියවර 1: "Array" එක කියන්නේ මොකක්ද? (The Container)
ඔයා හිතන්න ඔයා ගාව පොත් රාක්කයක් තියෙනවා කියලා. මේ රාක්කෙට අපි කියනවා Array එකක් කියලා. මුලින්ම මේක හිස්.

JavaScript වලදී අපි ඒක ලියන්නේ මෙහෙමයි:

JavaScript
let bookRack = []; // මේ [] වරහන් වලින් කියන්නේ මේක ලිස්ට් එකක් (Array) කියන එකයි.
පියවර 2: "Object" එක කියන්නේ මොකක්ද? (The Item)
දැන් ඔයා මේ රාක්කෙට දාන්න අලුත් පොතක් ගේනවා. ඒ පොතට නමක්, පිටු ගාණක් සහ මිලක් තියෙනවා. මේ විස්තර ගොඩට අපි කියනවා Object එකක් කියලා.

JavaScript වලදී ඔයා මේක දන්නවා:

JavaScript
let myNewBook = {
  name: "Madol Doowa",
  pages: 200,
  price: 500
};
පියවර 3: "Push" කියන්නේ මොකක්ද? (The Action)
දැන් ඔයාට ඕනේ අර පොත (myNewBook) අරගෙන රාක්කෙට (bookRack) දාන්න. අන්න ඒ ක්‍රියාවට තමයි අපි push කරනවා කියන්නේ.

සරලවම: රාක්කය.push(පොත)

JavaScript
bookRack.push(myNewBook);
දැන් රාක්කේ ඇතුලේ පොත තියෙනවා. bookRack දැන් පෙනෙන්නේ මෙහෙමයි: [{ name: "Madol Doowa", ... }]

පියවර 4: දැන් අපි ඔයාගේ Code එකට එමු
ඔයාගේ Code එකේ සිද්ධ වෙන්නේ උඩ ක්‍රියාවලියමයි. හැබැයි පොඩි වෙනස්කම් දෙකක් එක්ක.

රාක්කය (Array): ඔයාගේ Movies කියන ලිස්ට් එක.

පොත (Object): Postman එකෙන් එවන ඩේටා ටික එකතු කරලා අපි හදන newMovie එක.

අපි දැන් ඒ කෝඩ් එක ලියන හැටි පියවරෙන් පියවර හිතමු.

Step 4.1: දත්ත ටික එළියට ගැනීම (Unpacking)
ඔයා Postman එකෙන් එවනවානේ title, director, year කියලා දේවල් ටිකක්. ඒ ටික මුලින්ම අපි අතට ගන්න ඕනේ.

JavaScript
// request එකෙන් එන JSON දත්ත ටික කියවලා body කියන විචල්‍යයට දාගන්නවා
const body = await request.json();

// ඊට පස්සේ ඒක ඇතුලේ තියෙන අපිට ඕන දේවල් විතරක් වෙන් කරලා ගන්නවා (Destructuring)
const { title, director, year } = body;
Step 4.2: අලුත් පැකට් එකක් හැදීම (Create Object)
දැන් අපේ අතේ දත්ත ටික තියෙනවා. හැබැයි අපි මේක Movies ලිස්ට් එකට දාන්න කලින්, පිළිවෙළකට පැකට් කරන්න (Object එකක් හදන්න) ඕනේ. අර අපි "මඩොල් දූව" පොත හැදුවා වගේ.

JavaScript
const newMovie = {
  id: Movies.length + 1, // ID එක ඔටෝ හැදෙන්න දානවා (තියෙන ගාණ + 1)
  title: title,          // Postman එකෙන් ආපු නම
  director: director,    // Postman එකෙන් ආපු ඩිරෙක්ටර්
  year: year             // Postman එකෙන් ආපු අවුරුද්ද
};
Step 4.3: ලිස්ට් එකට දැමීම (The Push)
දැන් තමයි වැදගත්ම කොටස. අපි හදපු newMovie එක, අපේ ප්‍රධාන Movies ලිස්ට් එකට ඔබනවා.

JavaScript
Movies.push(newMovie);
මෙන්න මේ පේළිය ලිව්වම තමයි ඇත්තටම අර දත්ත ටික අර ලිස්ට් එකේ අගට ගිහින් එකතු වෙන්නේ.

සාරාංශය (ඔයා තනියම හිතන විදිය)
ඊළඟ පාර ඔයාට මේ වගේ එකක් ලියන්න ඕන වුණාම, මෙන්න මේ ප්‍රශ්න 3 ඔයාගේ ඔලුවෙන් අහන්න:

මම බඩු දාන්නේ කොහාටද? (Where?)

උත්තරය: Movies Array එකට. (ඒක [] එකක් වෙන්න ඕනේ).

මම දාන්නේ මොනවාද? (What?)

උත්තරය: newMovie කියන Object එක. (ඒක {} ඇතුලේ හදාගන්න ඕනේ).

මම කොහොමද දාන්නේ? (How?)

උත්තරය: Movies.push(newMovie);
